步骤 0 · 先做 · 无需训练

固定一份所有模型共用的评估清单

  1. 选图。 从 MSCOCO 的未见图中固定一批，预算紧可先选约 1,000 张。保存图像 ID、每张图对应的五条真实描述及采样 seed。Flickr30K 单独准备一份清单，仅供步骤 1B 使用。
  2. 查重。 把清单与每个模型实际用过的训练图 ID 求交集，要求为零。若用的是早停或选模的验证集，表头写“开发集”。先定好清单，再看模型得分。
  3. 定两种评估输入。 集合检索把五条描述作为一个候选，N 张图对 N 个集合。标准检索每条描述单独编码与打分，N 张图对 5N 条描述。前者用于目标对照和消融，后者用于基线补表与错例。
  4. 登记权重。 每行填模型、骨干、初始化、训练目标、微调或冻结范围、seed、最佳 epoch 和权重路径。旧表的划分或候选数不同，就用这份清单把同表各行一起重评。
交付 两份数据清单、一张模型权重台账、每个模型的训练图与评估图交集计数。
解决 后续差值不会因为换了图库、把训练图混进评估，或把集合和单条描述当成同一种任务而失去可比性。
执行细节 · 怎样建清单、做评估自检、算差值

0.1 把数据和权重写成两张清单

用原始图像 ID 连接训练集与评估集。同一图即使路径或文件名变了，仍用同一个 ID。逐模型算交集并保存命中列表。先检查图片能否读取、五条描述是否齐全及归属是否正确，在看分数之前定下排除项。任何一个模型额外丢图，先查原因。确需排除时，更新共用清单并把同表各行一起重评。

评估清单  dataset, split, image_id, image_path, caption_id, caption_slot, caption_text
权重台账  run_id, checkpoint, backbone, init_id, train_split, objective,
          seed, trainable_modules, image_batch, optimizer_steps, best_epoch, selection_metric
去重记录  run_id, n_train_images, n_eval_images, overlap_count, overlapping_ids, manifest_version

0.2 先用几张图验证正例关系

  1. 集合检索要求每张图对应一个集合，打分矩阵为 N×N。标准检索打分矩阵为 N×5N，记录每列 caption 的图像 ID。用 ID 判正例，方便检查重排后是否还对齐。
  2. 做一个小样本自检，把已知正例分数设成最高。集合 I2T/T2I 的 R@1 都应为 100%。标准 I2T 让任一条正 caption 居首即可命中，T2I 验证逐条 caption 各自指向正确的图。打乱候选列并同步重排 ID，结果应保持一致。
  3. 每次正式跑完核对有效样本数。集合任务两向各有 N 个查询。标准任务 I2T 有 N 个，T2I 有 5N 个。排序出现同分时，所有方法用同一套规则。图库太小以致无法定义相应 K 时，该格标为不适用。

0.3 保存每条查询的排名，再汇总

逐查询结果  run_id, manifest_version, protocol, direction, query_id,
            owner_image_id, best_positive_rank, hit_at_1, hit_at_5, hit_at_10
R@K（%）    = 100 × 正例排名 ≤ K 的查询数 / 有效查询数
差值（百分点） = 实验行的 R@K − 指定对照行的 R@K

关键差值用固定图库的配对 bootstrap。每次有放回地抽图像 ID，两个模型用完全相同的抽样。标准 T2I 把同一图的五条查询一起带入。重复约 2,000 次，用差值的 2.5% 与 97.5% 分位作区间。这个区间反映固定权重下的查询抽样误差，重训波动另用多 seed 报告。

验收 主表各行使用同一版本清单，图像 ID 交集为零，候选数与实际查询数可核对。原验证集参与过选模时，结果标成开发集。划分无法核实时，该行先列为待核验。

步骤 2 · R1 W2 / R3 · 先做 CLIP 对照

让 CLIP 也用五条描述一起训练

要回答 如果 CLIP 也按描述集合训练，MCDisp-Align 还领先多少？

  1. 先看在训 CLIP 的配置。 确认训练是单条描述配图，还是五条先聚合。原稿只明确了各方法评估时用同一组五条描述，回信里按实际配置说明训练目标。
  2. 补训练目标对照。 用相同的 ViT-L/14 初始化和图像 batch。CLIP-PairFT 每图也读五条描述，按描述位置分别算五个 B×B 双向对比 loss 后取平均。CLIP-SetFT 独立编码五条描述，先取平均中心，再按 Eq. (5) 算一个 B×B 双向对比 loss。固定图像、描述、温度和更新步数。若已有权重符合其中一项，直接复用。预算只够跑 SetFT 时，明确原 CLIP-FT 的描述曝光差异，结论限定为两种训练配方的比较。
  3. 把四行放在同一张集合检索表。 用 MSCOCO、固定五条描述分组和共同中心 cosine，比较 PairFT、SetFT、MCDisp w/o ℒalign、MCDisp Full。组成员由标注提前确定。再用步骤 1A 的独立描述结果看优势是否延伸到无预聚合的任务。
  4. 有余力再做 ProLIP-SetFT。 保留 ProLIP 的头，只换成 Eq. (2)、(4)–(5) 的集合匹配。与同骨干原目标 ProLIP 配对，单列 H/14 的结果。
交付 四行集合检索主表，加一列同协议的百分点差。
解决 PairFT → SetFT 衡量集合监督的收益。MCDisp w/o → Full 在同架构下衡量对齐 loss 的收益。若描述曝光量相同且 SetFT 追平 Full，可说明集合监督已能弥合这项差距。若 Full 仍领先，再用同架构消融单独说明对齐项贡献。
执行细节 · 把 PairFT 和 SetFT 做成只改训练目标的对照

输入。 每步用同样的 B 张不同图及各自的五条描述。两行用同一个预训练权重、同样的可训练层、图像 batch、更新步数、学习率、温度与选模规则。先记下原 CLIP-FT 是否符合这些条件，再决定复用还是补训。

PairFT  对第 k 个描述槽位（k = 1…5）：
        logits[i,j] = cosine(image[i], caption[j,k]) / 温度
        以 i = j 为正例，算图到文、文到图的交叉熵后取平均
        最后对 5 个槽位的 loss 再取平均

SetFT   对每张图的 5 个文本中心取平均，得到 set_center[j]
        logits[i,j] = cosine(image[i], set_center[j]) / 同一个温度
        以 i = j 为正例，算两向交叉熵后取平均

MCDisp  w/o 和 Full 都使用原稿 Eq. (4)–(5)
        两行的区别是是否加入 Eq. (6) 的对齐损失

开跑前抽一批。 检查两组读到的图像 ID 和五条描述 ID 是否相同，每个打分矩阵是否为 B×B，正例是否都在对角线。跑少量更新，确认 loss、梯度和权重更新有限，再开始正式训练。若显存限制导致需要调小图像 batch，两行一起调整并记录。

评估及读表。 四行都在固定的 MSCOCO 图库做集合检索，统一中心 cosine。先填 PairFT→SetFT 和 w/o→Full 的两项差值，再看 Full 与 SetFT 的余量。若 SetFT 与 Full 很接近但区间较宽，写“当前评估无法区分”，避免把证据不足解释为等效。若 Step 1A 的逐条检索没有同样增益，明确限定收益发生在集合任务。

步骤 3 · R1 W1/W4、R2 Q3 · 先查生效再跑消融

先确认损失项有信号，再量化关掉的影响

3A · 用固定一小批 MSCOCO 数据查梯度与数值

  1. 确认轮次。 从日志记下 KL、覆盖、方向项第一次启用的轮次和最佳 checkpoint 的轮次。原稿第 5 轮开启覆盖，第 9 轮方向项才开始，第 10 轮到满权重。如果最佳权重在第 9 轮前，就用同样训满 10 轮的 Full 和去方向模型另做配对。
  2. 逐项求梯度。 用已有 checkpoint，在同一批图上分别对各项 loss 求梯度，只记录结果，不更新权重。记下加权 loss、梯度范数和非零比例，重点看低秩 U 和文本方差头。缺少早期权重时标为缺测，后续运行再补采。覆盖未激活时先记录比例，单纯增大 β 不会让零梯度出现。
  3. 查方差有没有被加大两次。 同一批样本记录基础方差、低秩 U 增加的边际方差和 caption 目标边际。用“完整图像边际减目标边际”判断是否系统性偏大。记录文本方差围绕 0.04 的分布，并在同一权重上把文本方差固定成 0.04，看集合排序改变多少。
交付 一张诊断表，列出启用轮次、覆盖激活率、U 与文本方差的梯度、方差误差及排序变化。
解决 区分“公式有梯度路径”“本次训练真的有梯度”“推理打分直接用到了它”。覆盖长期为零或方向没有启用时，按日志直接说明。
执行细节 · 在哪些轮次测，怎么区分零梯度和没有梯度路径
  1. 固定诊断输入。 在开发集预先选固定的几批图，保存图像和描述 ID。优先读取已保存的第 2、5、8、9、10 轮及实际最佳 checkpoint。缺哪些轮就登记哪些轮缺测。用同一输入比较各轮，并记录每一项当时的实际系数。把固定批次的复算与真实训练日志分列，实际生效步数以训练记录为准。
  2. 单独计算每项。 对匹配、KL、覆盖、方向、方差正则分别求梯度。先记未加权 loss，再乘该轮的实际系数。对 U、图像方差输出和文本方差输出分别记梯度是否连接、范数与非零比例。同一批的各项使用同一次前向或完全相同的输入。
  3. 标明为何为零。 路径不存在写“未连接”，轮次权重为零写“未启用”，有路径且测得为零写“本批为零”。对覆盖再记正 caption 中 d²/D>1 的比例。某一批没激活时，只对该批和该 checkpoint 作结论。
  4. 留两条推理检查。 同权重把 U 置零，原 Eq. (4) 和标准中心 cosine 的排名应一致。另一次将文本方差固定为 0.04，保留相同文本中心与中心间协方差，只重算集合分数，记录 top-1 翻转率和 R@1 变化。
轮次 | 是否最佳权重 | loss 项 | 实际系数 | 原始值 | 加权值 |
      U 梯度状态/范数 | 图像方差梯度 | 文本方差梯度 | 覆盖激活率
方差检查  目标边际、基础边际、低秩增量、完整边际偏差、低秩占总方差比例
覆盖检查  d²/D 的 P50、P90、P99，超过 1 的比例及对应样本数

方差诊断逐维比较两组误差。基础误差为图像基础方差减目标边际，完整误差为基础方差加 diag(UU⊤) 后减目标边际。分别报告平均有符号误差和平均绝对误差，避免正负误差抵消。

验收 回答“U 是否生效”时，至少给出一条梯度记录、一条评分路径检查和一条重训对照。三条分别说明训练时的信号、推理时的直接使用和移除后的影响。
回信里怎么直接回答四个数学问题
  • U 用在哪里。 原稿 Eq. (4)、标准中心余弦和 KLdiag 都不直接用 U。覆盖项用完整协方差，hinge 激活时可向 U 回传。方向项约束 U 的列空间，未约束幅度。设 z=(Σv+εI)−1δ，则 ∂d²/∂U=−2zz⊤U。可用同一权重在评分时置零 U 验证评分路径，再由 3B 的对角重训检验训练作用。
  • 覆盖怎么算。 报 d²/D 的 P50/P90/P99 和超过 1 的比例，再报加权 hinge 与梯度。若要改阈值，把它单列为新增实验。
  • 方差是否重复。 Eq. (2) 的混合矩包含 caption 内方差和中心间协方差。潜在问题在 Eq. (6)，对角 KL 把基础方差拟合到完整目标边际，随后完整协方差还加 UU⊤。若实测超配，再将“扣除低秩边际贡献”作为单独修订。
  • 文本方差为什么接近 0.04。 这是方差正则的锚点。前三个对齐项的 sg 截断 caption 目标梯度，方差正则仍训练文本方差。ℒmatch 的方差梯度在前两轮关闭，再逐步开启。接近锚点时，结合跨样本变化和固定方差后的排序变化判断实际作用。

原稿默认 α=1、β=0.5、γ=0.01、η=0.01、r=4、v₀=0.04、ε=10−6。用实测的加权梯度回答不同损失尺度如何平衡。若某项实际有信号但移除前后差异很小，再考虑单独调大对应的 β 或 γ，保持其他项不变。
