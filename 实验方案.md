  ---
  技术路线：不确定性校准的分布对比学习

  1. 问题定义

  给定图文对数据集 $\mathcal{D} = (x_i, c_i^{(k)}{k=1}^K){i=1}^N$，其中 $x_i$ 为图像，$c_i^{(k)}$ 为其 $K$ 条描述文本。目标：将图像和文本映射到概率分布空间，使得分布的方差 $\sigma^2$ 显式编码语义不确定性。

  2. 整体架构

  3. 分布建模

  3.1 编码过程

  对图像 $x$ 和文本 $c$，通过冻结 CLIP 提取特征后，MLP 头将其映射为高斯分布参数：

  图像端:
    h_x = CLIP_image(x)              ∈ R^768      (冻结，不参与训练)
    μ_x = f_μ^img(h_x)               ∈ R^768      (可训练)
    log σ²_x = f_σ^img(h_x)          ∈ R^768      (可训练)

  文本端 (K 条描述各自独立编码):
    h_{c^{(k)}} = CLIP_text(c^{(k)})  ∈ R^768
    μ_{c^{(k)}} = f_μ^txt(h_{c^{(k)}})           ∈ R^768
    log σ²_{c^{(k)}} = f_σ^txt(h_{c^{(k)}})      ∈ R^768

  融合 (仅文本端):
    (μ_c, log σ²_c) = Merge({(μ_{c^{(k)}}, log σ²_{c^{(k)}})}_{k=1}^K)

  3.2 文本分布融合 (Moment Matching)

  将 $K$ 条描述的高斯分布融合为一个：

  $$\mu_c = \frac{1}{K} \sum_{k=1}^{K} \mu_{c^{(k)}}$$

  $$\sigma_c^2 = \frac{1}{K} \sum_{k=1}^{K} \left( \sigma_{c^{(k)}}^2 + \mu_{c^{(k)}}^2 \right) - \mu_c^2$$

  4. 三大损失组件

  组件1: 不确定性校准对比损失 $L_{calibratedCL}$

  核心思想：$\sigma$ 不强制对齐，而是调节相似度的锐度。不确定性大的样本获得更温和的梯度，不确定性小的样本获得更确定的梯度。

  $$sim(x, c) = \frac{\hat{\mu}_x \cdot \hat{\mu}_c}{\tau \cdot \sqrt{1 + \bar{\sigma}_x^2} \cdot \sqrt{1 + \bar{\sigma}_c^2}}$$

  其中：
  - $\hat{\mu} = \mu / \mu$ 为 L2 归一化均值
  - $\bar{\sigma}^2 = \frac{1}{D}\sum_{d=1}^{D} \sigma_d^2$ 为逐维方差均值（非求和）
  - $\tau$ 为温度超参数

  $$L_{calibratedCL} = -\frac{1}{2}\left[ \log \frac{\exp(sim(x_i, c_i))}{\sum_j \exp(sim(x_i, c_j))} + \log \frac{\exp(sim(c_i, x_i))}{\sum_j \exp(sim(c_i, x_j))} \right]$$

  数学直觉：
  ┌───────────────┬───────────────────────────┬──────────────────────────────────┐
  │ $\sigma$ 大小 │ $\sqrt{1+\bar{\sigma}^2}$ │               效果               │
  ├───────────────┼───────────────────────────┼──────────────────────────────────┤
  │  $\approx 0$  │        $\approx 1$        │ 标准对比学习，logits 尖锐        │
  ├───────────────┼───────────────────────────┼──────────────────────────────────┤
  │     $= 1$     │ $= \sqrt{2} \approx 1.41$ │ 有效温度 $2\times$，梯度稍温和   │
  ├───────────────┼───────────────────────────┼──────────────────────────────────┤
  │     $= 3$     │           $= 2$           │ 有效温度 $4\times$，梯度明显温和 │
  └───────────────┴───────────────────────────┴──────────────────────────────────┘
  组件2: 分布一致性约束 $L_{consist}$ (核心创新)

  核心洞察：图像 $\sigma^2$ 应等于其所有描述均值的散度。这是 ProLIP、D2P 都没有的显式约束。

  $$L_{consist} = \text{MSE}\left(\sigma_x^2, \ \text{Var}{k=1,...,K}(\mu{c^{(k)}})\right)$$

  展开：

  $$L_{consist} = \frac{1}{B \cdot D} \sum_{i=1}^{B} \sum_{d=1}^{D} \left( \sigma_{x,i,d}^2 - \frac{1}{K}\sum_{k=1}^{K}(\mu_{c^{(k)}{i,d}} - \bar{\mu}{c,i,d})^2 \right)^2$$

  为什么这是对的：
  - 若一张图有 5 条语义相似的描述 $\Rightarrow$ $\text{Var}(\mu_c)$ 小 $\Rightarrow$ $\sigma_x^2$ 被约束为小 $\Rightarrow$ 模型"确信"这张图有一个明确的语义
  - 若一张图有 5 条语义多样的描述 $\Rightarrow$ $\text{Var}(\mu_c)$ 大 $\Rightarrow$ $\sigma_x^2$ 被约束为大 $\Rightarrow$ 模型"知道"这张图语义模糊

  与现有工作的本质区别：

  ProLIP:  σ 由 loss 隐式决定，语义不明确
           "σ 大 → 不确定" (但不确定什么？)

  本文:    σ² ≡ Var(μ_captions)，语义明确
           "σ 大 → 描述多样 → 语义多义" (可验证)

  组件3: 方差正则化 $L_{var}$

  防止 $\sigma$ 坍塌到 0 或爆炸：

  $$L_{var} = \text{MSE}(\sigma_x^2, \mathbf{1} \cdot \sigma_0^2) + \text{MSE}(\sigma_c^2, \mathbf{1} \cdot \sigma_0^2)$$

  其中 $\sigma_0^2$ 为目标方差（超参数，默认 0.5）。

  总损失

  $$L_{total} = \lambda_{cl} \cdot L_{calibratedCL} + \lambda_{consist} \cdot L_{consist} + \lambda_{var} \cdot L_{var}$$
